# Bio-Face-Secure

Conception, développement et déploiement d’un système sécurisé d’authentification biométrique par reconnaissance faciale avec détection d’attaques et protection des données sensibles

Fonctionnalités attendues
Capture d’image via webcam 
Détection et encodage du visage 
Comparaison avec base de données 
Gestion des utilisateurs 

Partie attaque (obligatoire)
tentative avec photo ou vidéo 
contournement du système 

Partie défense
détection de “liveness” (clignement, mouvement) 
seuil de similarité ajusté 
chiffrement des données biométriques
